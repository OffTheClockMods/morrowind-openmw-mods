Skill Gain Multiplier (OpenMW) 1.0.0 - by Off the Clock
=======================================================
Faster or slower skill training from use, x0 to x100. For OpenMW 0.50 or newer (not MWSE / Morrowind.exe).

Install: add this folder in the OpenMW Launcher (Data Files > Data Directories), then tick
OtcSkillGainMultiplier.omwscripts in the content list.
Settings: in the game, Options > Scripts > Skill Gain Multiplier. x1 = the normal game (the default).
Final speed = All skills x the specialization (combat / magic / stealth) x the single skill.
Books, trainers and jail are not changed. Nothing is written to your saves; safe to add or remove any time.
Uninstall: untick the .omwscripts file.
